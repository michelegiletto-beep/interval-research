# Evidence distribution

This repository contains the final dense and sparse metric tables, protocols and summaries, the monotone-transform summary, figures and environment record.

The [complete release archive](https://huggingface.co/spaces/Magic51/interval-research/resolve/main/interval-source.tar.gz) additionally includes all 210 raw fitting records, the showcase inference bundle, the adapter and a file-by-file SHA-256 manifest. Extract it into a separate directory to inspect or verify the complete release without mixing local outputs.

The numerical scripts reproduce these artifacts from deterministic seeds. The reported results use synthetic observations; no satellite, clinical or physical-QPU dataset is included.
